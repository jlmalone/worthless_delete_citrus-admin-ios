# 🍊 Citrus Admin iOS

Part of the Citrus Enterprise Receipt Intelligence Platform.

## Status

✅ **COMPLETE** - iOS Admin Dashboard Ready

## Overview

Full-featured iOS admin dashboard built with Swift and SwiftUI for the Citrus Enterprise Receipt Intelligence Platform.

## Features

- **📊 Dashboard Analytics**: Real-time metrics, KPIs, and visual analytics
- **👥 User Management**: Complete user administration with role-based permissions
- **🧾 Receipt Review**: Approve, reject, and manage receipts with detailed views
- **🔔 Alerts & Notifications**: System alerts with severity tracking and resolution

## Tech Stack

- **Language**: Swift
- **UI Framework**: SwiftUI
- **Reactive Programming**: Combine
- **Architecture**: MVVM (Model-View-ViewModel)
- **Minimum iOS**: 15.0+

## Project Structure

```
CitrusAdmin/
├── Models/              # Data models (User, Receipt, Analytics, Alert)
├── ViewModels/          # Business logic with Combine
├── Views/               # SwiftUI views
├── Services/            # Data and API services
└── Utilities/           # Helper extensions
```

## Quick Start

1. Open `CitrusAdmin.xcodeproj` in Xcode
2. Select target device (iPhone or iPad)
3. Build and run (⌘R)
